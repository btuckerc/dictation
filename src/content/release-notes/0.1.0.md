A quieter Dictation, with its own identity.

- Neutral settings panels, custom accent colors, and concise tooltip help.
- Double-tap or hold shortcuts, with macOS Fn setup guidance.
- History transcripts start collapsed; expand any entry to read it.
- Compact permission setup with a draggable app icon.
- Dictation project links, independent versioning, and offline open-source credits.

Based on Handy by CJ Pais and contributors.
